# حاسبات الرهن العقاري لـ 50 ولاية أمريكية

موقع ثابت (بدون سيرفر) يولّد 50 صفحة، صفحة لكل ولاية، وصفحة رئيسية فيها حاسبة بكل الولايات. الأرقام تنسحب من مصادر رسمية:

- **نسبة الفائدة:** Freddie Mac عبر FRED (أسبوعياً)
- **قيمة البيوت وضريبة العقار والدخل:** Census Bureau، مسح ACS (سنوياً)

ما في أرقام مكتوبة باليد. إذا ما شغّلت سحب البيانات، البناء يرفض يشتغل.

> **ملاحظة عن هذه النسخة:** الملفات هنا مسطحة (بدون مجلدات) حتى تنرفع من الموبايل. ملف `update.yml` (يجب أن يكون مساره `.github/workflows/update.yml`) فيه خطوة "Restore project folders" ترجّع المجلدات (`src`, `scripts`, `assets`, `test`) أثناء البناء على GitHub. لا تغيّر أسماء الملفات.

## أول تشغيل (على جهازك)

تحتاج Node.js 22 أو أحدث.

1. سجّل مفتاح Census مجاني (دقيقتين، يوصلك على الإيميل): https://api.census.gov/data/key_signup.html
2. فعّل المفتاح من الرابط اللي يوصلك بالإيميل.
3. شغّل:

```
CENSUS_API_KEY=مفتاحك npm run update
python3 -m http.server -d dist 8000
```

افتح http://localhost:8000 وشوف الموقع.

## النشر المجاني مع تحديث تلقائي (GitHub Pages)

1. سوّي حساب GitHub ومستودع **عام** (public) وارفع هذا المجلد عليه (الفرع `main`).
2. من Settings → Secrets and variables → Actions أضف سر باسم `CENSUS_API_KEY` وقيمته مفتاحك.
3. من Settings → Pages اختر Source: **GitHub Actions**.
4. بعدها الموقع ينبني وينشر لحاله كل خميس (بعد صدور نسبة Freddie Mac)، وكل ما ترفع تعديل. ما تحتاج تسوي شي.
5. للدومين الخاص: اشتر دومين، وربطه من Settings → Pages → Custom domain.

## قبل النشر الفعلي

- عدّل `config.json`: `siteName`, `siteUrl` (دومينك الحقيقي), `contactEmail`.
- الصفحات القانونية (الخصوصية، الإخلاء، تواصل) موجودة وتنولّد لحالها. راجع نص الخصوصية وتأكد يطابق حالتك.
- **غوغل يحتاج محتوى مفيد لكل صفحة.** كل صفحة فيها أرقام وفقرات مختلفة محسوبة من بيانات الولاية. لتقوية الترتيب أضف ملف `content/اسم-الولاية.html` (مثلاً `content/texas.html`) فيه معلومات محلية حقيقية تتأكد منها بنفسك (برامج المشتري الأول، إعفاءات ضريبة العقار، وغيرها). يظهر تحت قسم "Buying a home in ...".
- تأمين البيت: الأرقام الافتراضية تقدير عام (0.4% من سعر البيت سنوياً) وليس رقم رسمي لكل ولاية. إذا لقيت مصدراً موثوقاً، أضف `data/insurance-rates.json` بهذا الشكل وسيُستخدم تلقائياً:

```json
{ "florida": 1.1, "texas": 0.9 }
```

## الإعلانات (AdSense)

1. اطلب قبول الموقع من Google AdSense بعد نشره وصار عليه محتوى وزيارات. القبول ممكن يستغرق أسابيع.
2. بعد القبول حط معرّفك في `config.json` → `adsenseClient` (مثل `ca-pub-1234567890123456`). الموقع يضيف سكربت الإعلانات وملف `ads.txt` تلقائياً، والإعلانات تتوزع بالإعلانات التلقائية.
3. إذا الزوار من أوروبا أو بريطانيا، غوغل يطلب رسالة موافقة على الكوكيز. فعّلها مجاناً من حسابك في AdSense (Privacy & messaging).
4. تحقق من طريقة استلام الأرباح المتاحة لك في العراق من إعدادات الدفع داخل حساب AdSense.

## ملاحظة صريحة

زيارات غوغل تحتاج غالباً من 3 إلى 6 شهور حتى تظهر، والدخل بالبداية يكون صغير. المنافسة على كلمات مثل "Texas mortgage calculator" قوية، والفرصة بالصفحات اللي تضيف شي حقيقي (محتوى محلي، دقة، سرعة).
